Avisos viram `prevcarga_warn("warning.<what>")` (um por `what`): stderr no texto, `warnings` no JSON.
  Veredito reprovado => `prevcarga_abort(<classe>.<what> do 1o erro da classe dominante, details = {findings, items, origin})`; o exit (2/3/4/5) vem so do handler de topo. No texto o resultado completo tambem vai a stdout antes do abort.
